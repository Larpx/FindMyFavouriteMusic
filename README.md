# Find My Favourite Music

根据你标记「喜欢」的歌曲，学习听歌口味，并对新歌给出匹配分数的桌面应用。

[English](README.en.md) · [用户使用说明](docs/用户使用说明.md) · [开发说明](docs/开发说明.md)

---

## 它能做什么

- 扫描本地音乐库，浏览并管理歌曲
- 标记喜欢，自动形成个人品味画像
- 预测某首歌有多符合你的口味（0–100）
- 在详情中编辑标题、封面等标签，并写回原文件
- 可选深度模型，提升分析能力（没有也能用）

---

## 程序怎样工作（简要）

1. **扫描**音乐文件夹，分析每首歌的听感特征并入库  
2. 你给喜欢的歌点爱心，程序据此**更新品味画像**  
3. 在「预测」页选择或拖入歌曲，得到与画像的**匹配分数**

细节见 [用户使用说明](docs/用户使用说明.md)；算法原理见 [算法说明](docs/算法说明.md)。

## 快速开始

**需要**：Windows 10+（推荐）、[.NET 10 SDK](https://dotnet.microsoft.com/download)（从源码运行时）

```bash
cd src
dotnet build
dotnet run --project FindMyFavouriteMusic.GUI
```

1. 打开 **音乐库** → 扫描目录 → 给几首歌点喜欢  
2. 打开 **预测** → 选择或拖入文件 → 查看分数  
3. 需要时在 **设置** 中调整权重或加载深度模型  

更完整的操作步骤与常见问题：[用户使用说明](docs/用户使用说明.md)。
