# 测试与覆盖说明

## 运行测试

```bash
cd src
dotnet test FindMyFavouriteMusic.Tests --filter "FullyQualifiedName!~Hardware"
```

硬件/ONNX 集成与基准测试（需本机模型与 OpenVINO）单独运行：

```bash
dotnet test FindMyFavouriteMusic.Tests --filter "FullyQualifiedName~Hardware"
```

覆盖率（Cobertura）：

```bash
dotnet test FindMyFavouriteMusic.Tests --filter "FullyQualifiedName!~Hardware" \
  --collect:"XPlat Code Coverage" --results-directory ../TestResults
```

## 覆盖范围约定

| 范围 | 策略 |
|------|------|
| Models / Services 业务路径 / Core 工具类（Hasher、Lock、Format、Preprocessor、Normalizer、相似度等） | 单元 + 内存 SQLite 集成测试，目标高覆盖 |
| TagLib 标签读写 | 真实临时 WAV 文件往返 |
| ONNX 提取器（VGGish/MERT）/ Hardware / Avalonia View·ViewModel | 依赖本机模型或 UI 宿主，**不强制**纳入日常全覆盖门槛 |
| GUI 交互 | 以手工验收 + 服务层契约测试为主 |

说明：整仓 line-rate 受 ONNX/Hardware 拖累会偏低；日常以 `!~Hardware` 过滤后的 **Services / Models / Core 可测子集** 为准。A–D 阶段新增契约（200MB、MD5 skip、画像清空、AppData 设置、标签写回）均有对应自动化用例。

参考实测（2026-07-28，`!~Hardware` + Cobertura）：Models **100%**，Services **~82%**，Core 整体偏低（ONNX/解码路径未进日常集）；工具类（Hasher / Lock / Format / Preprocessor / Normalizer）已有用例。

## 建议门槛（日常 CI）

| 程序集 | 建议 |
|--------|------|
| Models | ≥ 90% line |
| Services（排除 Hardware 相关） | ≥ 80% line |
| Core 工具类（非 ONNX/Hardware） | 关键公共 API 有用例 |

Hardware / ONNX 集成测试单独跑，不阻塞日常 CI。
