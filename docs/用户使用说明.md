# 用户使用说明

本文面向**一般用户**，介绍如何安装、理解和使用 **Find My Favourite Music（音乐品味预测）**。  
开发者请参阅 [开发说明](开发说明.md)；算法与数据处理细节见 [算法说明](算法说明.md)。

---

## 1. 这是什么

这是一款桌面程序：扫描你电脑上的音乐，根据你标记为「喜欢」的歌曲，学习你的听歌口味，再对新歌曲给出 **0–100** 的匹配分数，帮助你发现更可能喜欢的歌。

主要能力：

- 扫描本地音乐库并浏览、管理
- 用「喜欢」建立个人品味画像
- 对单首歌曲做喜好预测（也可拖入文件）
- 在详情里编辑歌曲标签与封面（直接写回原文件）
- 在设置里调整权重、可选深度模型等

---

## 2. 程序大致怎么跑（不用懂技术）

可以把它想成一条流水线：

1. **导入音乐**：扫描文件夹，把能识别的音频记进本地曲库（过大的单文件会被拒绝，约 200MB）。
2. **分析歌曲**：程序从每首歌里提取「听感特征」（可选地再用深度模型加强），并缓存结果；同一文件未改动时，再次扫描通常会跳过重复分析。
3. **建立画像**：你点击爱心标记喜欢后，程序根据这些喜欢的歌，汇总成一份「品味画像」。
4. **做预测**：你选一首（或拖入）待测歌曲，程序把它和画像比较，得到匹配分数并展示。

更细的数据处理与公式见 [算法说明](算法说明.md)。

## 3. 开始使用

### 3.1 需要什么

- Windows 10 及以上（推荐；FLAC / M4A 在 Windows 上支持更完整）
- 若从源码运行：安装 [.NET 10 SDK](https://dotnet.microsoft.com/download)
- （可选）深度模型文件：开启后预测可能更准；没有时程序仍可用「仅声学」模式

### 3.2 启动

若使用发行包：直接运行安装目录中的程序即可。

若从源码启动：

```bash
cd src/FindMyFavouriteMusic.GUI
dotnet run
```

首次启动会在本机创建曲库数据库；你在设置页改过的选项会保存在用户目录，下次打开仍然有效。

## 4. 功能指引

主窗口左侧有三个页面：**音乐库**、**预测**、**设置**。

### 4.1 音乐库

1. 点击「扫描目录」，选择存放音乐的文件夹。
2. 等待进度完成，列表中会出现歌曲。
3. 点击爱心标记喜欢 / 取消喜欢（已喜欢再点喜欢不会重复计算）。
4. 单击某首歌（或右键进入详情），可在右侧查看封面与标签，编辑后点「保存到原文件」。
5. 可用「刷新列表」重新加载已入库的歌曲。

说明：

- 支持常见格式如 MP3、WAV；FLAC、M4A 在 Windows 上一般可用。
- 封面与标签保存在音乐文件里；列表信息会同步更新。
- 取消全部喜欢后，品味画像会被清空，需重新标记喜欢。

### 4.2 预测

1. 先在音乐库里至少喜欢一首歌。
2. 打开「预测」页，选择文件或把音频拖进放置区。
3. 点击开始预测，查看总分以及声学 / 深度分项（若已启用深度特征）。

分数可粗略理解为：越高越接近你当前的喜欢口味（界面会用颜色提示高低）。

### 4.3 设置

常见可调项：

- 声学 / 深度权重（两者之和建议为 1）
- 是否启用深度模型、模型路径与推理相关选项
- 扫描时同时处理几首歌
- 「加载模型」「重建画像」

「保存」会写入你的用户配置；「加载模型」会立刻尝试把模型载入内存。部分推理相关选项改完后需要重启程序才完全生效。

## 5. 常见问题

**预测按钮提示要先构建画像？**  
先到音乐库给至少一首歌点上喜欢。

**分数整体偏低？**  
喜欢的样本太少、风格跨度很大，或尚未启用深度模型时都可能发生。可多标几首真正喜欢的歌，或在设置中重建画像。

**扫描很慢？**  
第一次分析整库本来就更耗时；开启深度模型会更慢。可先关深度扫完，再按需开启。已分析过且文件未改的歌，再次扫描通常会快很多。

**改了设置好像没生效？**  
确认已点保存；部分项需重启。从源码运行时，默认配置文件在程序输出目录，用户配置在系统「应用数据」目录下的 `FindMyFavouriteMusic` 文件夹。

**数据库在哪？**  
默认在程序运行目录下的 `findmyfavouritemusic.db`（具体路径以实际安装/运行位置为准）。
